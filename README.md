# ✦ Alice — Portfólio Interativo

Uma experiência visual inspirada em *Alice no País das Maravilhas*, construída como portfólio criativo com HTML, CSS e JavaScript.

🔗 **Veja ao vivo:** [LINK-AQUI](LINK-AQUI)

---

## 🕳️ A experiência

Você cai. A tela escurece. Algo espera no escuro.

Alice é um projeto de narrativa interativa onde cada clique revela um novo momento da história, com animações, efeitos de luz, sons e transições contadas em código.

---

## 🎮 Controles

| Dispositivo | Ação |
|-------------|------|
| Desktop | Mouse move a lanterna, seta ↑ aproxima da porta, clique na maçaneta |
| Celular / tablet | Toque e arraste move a lanterna, swipe para cima aproxima da porta, toque na maçaneta |

Dica: use fones de ouvido. 🎧

## 🛠 Tecnologias

* HTML, CSS e JavaScript (sem frameworks)
* Flask (Python): servidor local de desenvolvimento
* Web Audio API: sons ambiente gerados por código (gotas e arrasto)
* Áudios (`.wav`): as vozes da experiência
* Artes originais desenhadas por mim
* Deploy: Netlify (site estático)

---

## 💻 Rodando localmente

```bash
pip install -r requirements.txt
python app.py
```

Depois abra `http://localhost:5000`.
